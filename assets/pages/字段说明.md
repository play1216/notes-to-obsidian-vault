# 字段说明

每篇条目笔记头上的字段，都是给**查询**和**复习**用的，不是给人读的装饰。改字段名之前先想清楚有没有查询依赖它。

## 档案字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `{{ID}}` | 文本 | 唯一编号，形如 `1.27-2`。**不要改**，双链靠它定位 |
| `日期` | 日期 | 原页日期，和 `{{PAGES}}` 里的文件名一一对应 |
| `短引用` | 文本 | `1.27` 这种当天短号，方便口头称呼 |
| `章节` | 文本 | 归档章节。以**文件所在文件夹**为准，两者不一致时按文件夹算 |
| `章节待确认` | 布尔 | 迁移时自动归类把握不大的条目会带这个标记，人工复核后删掉即可 |
| `本页第几题` / `本页共几题` | 数字 | 定位用：照片是整页，靠这两个数在图上找 |
| `题型` | 文本 | 原笔记里的分类，未做归一化 |
| `难度` | 数字 1–5 | 存数字不存星星，方便 `WHERE 难度 >= 4` |
| `状态` | 文本 | 复习状态，初始统一为「待摸底」 |
| `来源` | 文本 | 出处，多为「老师讲解」 |
| `照片` | 文本 | 原图文件名，对应 `{{ASSETS}}/原图/` 下的实际文件 |
| `知识点` | 列表 | 原标签原文，保留不改写 |
| `方法` | 列表 | 原方法标签原文。母方法双链在正文里，不在这里 |

## 标签

`tags` 里是四类，都带层级，方便在标签面板里折叠：

- `条目` — 所有条目笔记
- `章节/xxx` — 与 `章节` 字段同步
- `知识点/xxx` — 细粒度，数量多，主要靠搜索
- `方法/xxx` — 原始方法标签，可能是"一次性描述"

> **为什么标签要带前缀**：源笔记里写的是 `` `#数列` ``，反引号包着在 Obsidian 里只是行内代码，点不动也搜不到。迁移时必须改成真正的标签（放进 `tags:` 或写成裸 `#xxx`），否则这套索引等于不存在。

## 双链

- **母方法** → 正文顶部 `> 方法 [[换元法]]`，方法页的反链就是"这招我用过哪些条目"
- **原页** → `> 原页 [[2026-01-27]]`，跳到整页照片和原始记录
- **交叉引用** → 正文里出现的其他编号会自动转成 `[[1.27-1|1.27-1]]`，公式和行内代码里的数字不会被误伤

## 想加字段

加到 frontmatter 里，然后在 [[可选查询（需 Dataview）]] 里用。别加在同名正文段落里——那会让 `WHERE` 查不到。
